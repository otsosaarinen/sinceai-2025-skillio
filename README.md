## About the Project

This repository contains the project developed during the Since AI Hackathon. The challenge we took on was the **SkillIO Company Challenge**, which focused on creating innovative solutions to address real-world problems faced by SkillIO.

## Project Structure
The project is organized into the following main directories:
- `frontend/`: Contains the frontend application code.
- `backend/`: Contains the backend application code.

# Usage Instructions
Please refer to the `README.md` files located in the `frontend/` and `backend/` directories for detailed setup and usage instructions for each part of the project.
